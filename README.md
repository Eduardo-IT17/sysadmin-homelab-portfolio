# 🛠️ Systems & Infrastructure Home Lab Portfolio

Bienvenido a mi portafolio de laboratorios y documentación técnica. En este repositorio documento la configuración, despliegue y resolución de incidencias (*troubleshooting*) en entornos de prueba de administración de sistemas, redes y ciberseguridad.

---

## 💻 Entornos y Tecnologías Trabajas

- **Sistemas Operativos:** Linux (Ubuntu, Debian), Windows Server (Active Directory, GPOs).
- **Redes y Seguridad:** Configuración IP, VLANs, Firewalls, Wireshark, Análisis de tráfico.
- **Virtualización:** VMware Workstation, VirtualBox, KVM.
- **Gestión de Servicios & ITSM:** Protocolos de ticketing, documentación de incidencias N2, scripts en Bash/PowerShell.

---

## 📂 Estructura de Proyectos

Below is an overview of the technical documentation available in this repository:

1. **`01-Linux-Administration/`**
   - Configuración de servidores web (LAMP/LEMP).
   - Gestión de usuarios, permisos y hardening del sistema.
2. **`02-Windows-Server/`**
   - Instalación y gestión de Active Directory y Servicios DNS/DHCP.
   - Creación y despliegue de Políticas de Grupo (GPO).
3. **`03-Networking-Security/`**
   - Captura y análisis de paquetes con Wireshark.
   - Configuración básica de Firewalls e inspección de tráfico.

---

## 🎯 Objetivo Profesional

Documentar la resolución metódica de problemas técnicos (*troubleshooting*) y el mantenimiento de infraestructuras IT seguras y eficientes.

> *"La mejor forma de solucionar una incidencia es comprender a fondo la infraestructura que la soporta."*
